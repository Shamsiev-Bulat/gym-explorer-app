# 🏋️ Fit Exercises PWA

Современное, быстрое и адаптивное веб-приложение (Progressive Web App) для просмотра базы фитнес-упражнений. Оптимизировано для мобильных устройств (iOS/Android) и работает прямо в браузере без необходимости установки через App Store или Google Play.

## ✨ Возможности
- 📱 **Mobile-First дизайн**: Интерфейс, адаптированный под тач-управление и безопасные зоны современных смартфонов.
- 🌍 **Мультиязычность**: Поддержка инструкций на 10 языках (Русский, English, Español, Türkçe и др.).
- 🔍 **Умный поиск и фильтры**: Мгновенный поиск по названию, тексту инструкции, группе мышц или типу оборудования.
- 🎬 **Визуализация**: Анимированные GIF и статические изображения для каждого упражнения.
- ⚡ **Высокая производительность**: "Ленивая" загрузка изображений и оптимизированный рендеринг списка.

## 🛠 Технологии
- HTML5, CSS3 (CSS Variables, Flexbox, Backdrop Filter)
- Vanilla JavaScript (ES6+, Fetch API, Local Storage ready)
- Данные загружаются напрямую из открытого API/JSON репозитория

## 🚀 Как запустить
1. Клонируйте репозиторий или скачайте файл `index.html`.
2. Откройте файл в любом современном браузере.
3. *(Рекомендуется)* Для корректной работы CORS при локальном запуске используйте расширение "Live Server" в VS Code или любой простой локальный сервер (например, `python -m http.server`).
4. На мобильном устройстве: откройте ссылку на хостинг (например, GitHub Pages) и выберите **"Добавить на главный экран"** (Add to Home Screen).
